🎬 FreeVideoSubtitle

**FreeVideoSubtitle** is a free, open-source desktop application built with Python that automatically generates and burns subtitles into any video using AI. 

No paid subscriptions, no API limits, and no watermarks — everything runs 100% locally on your computer.

---

## ✨ Features

* 🌍 **Multi-Language Support:** Automatic speech recognition supporting 10+ languages.
* 🎨 **Full Customization:**
  * Custom font selection.
  * Adjustable text size, colors, and background/shadows.
  * Subtitle speed and timing control.
* ⚡ **100% Free & Local:** Runs entirely on your hardware with no internet connection required for processing.
* 📹 **Universal Support:** Works with MP4, MKV, AVI, and other popular video formats.

---

## 🚀 How to Run

### Option 1: For Users (Pre-compiled Executable)
1. Go to the **[Releases](../../releases)** section on the right side of this repository.
2. Download the `FreeVideoSubtitle.zip` archive.
3. Extract the files and run `FreeVideoSubtitle.exe`.

---

### Option 2: For Developers (Run from Source)

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/UndefinedNuke/FreeVideoSubtitle.git](https://github.com/UndefinedNuke/FreeVideoSubtitle.git)
   cd FreeVideoSubtitle

```

2. **Install dependencies:**
```bash
pip install -r requirements.txt

```


3. **Ensure FFmpeg is installed:** Place `ffmpeg.exe` in the project root directory.
4. **Run the app:**
```bash
python subtitle_app.py

```
